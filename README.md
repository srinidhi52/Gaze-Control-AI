# 🌟 GazeControl AI
**An Edge-AI Accessibility Tool for Hands-Free Computer Navigation.**

Built by srinidhi

## 🚀 The Vision
Commercial eye-tracking hardware costs thousands of dollars. **Gaze Control-AI** turns any standard laptop webcam into a powerful, hands-free accessibility device. Built entirely with Edge-AI, it processes video locally without internet, ensuring 100% user privacy. 

## ✨ Features
- **🖱️ Face-Tracked Gliding:** Smoothly maps nose movements to the mouse cursor.
- **👈 Left-Wink to Click:** Completely hands-free left-click functionality.
- **👉 Right-Wink for Voice:** Triggers the microphone to dictate voice-to-text.
- **📜 Jaw-Drop & Smile Scrolling:** Open mouth to scroll down, smile wide to scroll up.
- **🛑 Global Kill-Switch:** Built-in failsafe (ESC key) to immediately stop.
